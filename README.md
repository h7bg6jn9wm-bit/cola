SHK Theorie Trainer V106
- Konto-/Anmeldescreen vor dem Hauptmenü
- Erststart: Konto einrichten mit Benutzername und Passwort
- Danach: Anmeldung vor dem Hauptmenü
- Passwort wird lokal als SHA-256-Hash gespeichert
- Lernstand und Ergebnisse bleiben lokal erhalten
- Abmelden im Hauptmenü möglich
Hinweis: Dies ist eine lokale Anmeldung auf dem Gerät, kein Online-Konto mit Server-Synchronisierung.
